# Publication checklist

- [ ] Select a project license.
- [ ] Review QNN sample/interface-derived source redistribution terms.
- [ ] Review Hexagon-MLIR/Triton kernel-source and generated-object terms.
- [ ] Confirm `NOTICE` and `THIRD_PARTY.md` attribution.
- [ ] Run all host tests.
- [ ] Run licensed Linux builds from a clean checkout.
- [ ] Run V69 correctness validation.
- [ ] Run `tools/audit_repository.py`.
- [ ] Inspect `git ls-files` for SDK binaries and private identifiers.
- [ ] Obtain explicit approval before creating or pushing a public remote.
