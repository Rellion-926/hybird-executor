# Publication gate

This repository is being prepared for collaborator use. A public GitHub push is intentionally blocked until:

1. the project license is selected;
2. source and binary provenance is reviewed;
3. `NOTICE` and `THIRD_PARTY.md` are complete;
4. the repository audit passes;
5. the maintainer explicitly approves creation or use of a public remote.

Qualcomm QAIRT/QNN, Hexagon SDK/Tools, Android NDK, and device runtime binaries are external dependencies and are not redistributed here.
